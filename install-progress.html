What to demonstrate

  1. Overview: change a level's install stage, then Undo.
  2. Timeline: pick an activity to see its walls and model vs P6 progress.
  3. Calendar: choose a day and preview the planned installation.
  4. Lookahead: review three weeks of open work and click a task for context.
  5. Export the progress CSV; reload to show browser persistence.

What IT should know

Hosting
Standalone browser workspace. No software installation or Revit connection required.
Model access
Existing APS-translated public sample model. A server-held token service issues temporary read-only viewer access. This tool does not upload or translate models.
Data storage
Each browser holds its own stages and imported schedules. No shared progress database, company SSO, or live team sync is implemented.
File imports
PDF, XER, XLSX and CSV are parsed in the browser. PDF reading loads PDF.js from jsDelivr.
Network
Allow this site, the Autodesk Viewer/APS services and jsDelivr for PDF imports. Confirm those endpoints on the IT network.
Production decisions
Identity, project access, shared storage, audit history, retention and backups need an agreed rollout plan.
