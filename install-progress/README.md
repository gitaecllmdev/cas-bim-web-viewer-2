# CAS Project Schedule Dashboard

Standalone Wilton Hotel workspace, with a flexible model/dashboard divider, management summary, Field, Timeline, Calendar and three-week Lookahead. Demo cost plan and Revit/cost integration preview use sample records only; no external system sync. Schedule and field stages are synthetic and linked to actual model levels. Browser-local edits; read-only model. No other tools are included.

GitHub Pages: deploy main branch, root folder. Uses the existing server-held read-only APS token service. No credentials, client schedule or server write routes are packaged.
