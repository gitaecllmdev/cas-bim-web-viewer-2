WORKSPACE HELP

Track the work. See what comes next.

Start here

  1. Dashboard: review the priority activities and illustrative cost forecast. Click an item to see its model context.
  2. Resize: drag the divider between model and dashboard, or use Model focus / Balanced / Schedule focus. Arrow keys also move the divider.
  3. Choose a level above the model to focus on one floor. Choose All levels to return to the building.
  4. Field: change a level's install stage, or select walls in the model and update only those walls. Undo restores the previous change.
  5. Timeline: click an activity to see its walls, dates and progress. Use the filters to find open work.
  6. Calendar: click a day number to preview planned installation. Click an activity bar for its details.
  7. Lookahead: review three weeks of open work. Change the start date or click a task for model context.

Import a schedule
Use Upload in the schedule bar. PDF, XER, XLSX and CSV are supported. Your file is read in this browser.
Export your work
Open the schedule's ⋯ menu and choose Export CSV for the activity comparison.
Save and reset
Edits save automatically in this browser. Reset demo restores the demonstration schedule and field stages after confirmation. Other browsers have their own copy; changes are not shared with a team.
What the colors mean
Yellow: Framed. Blue: Boarded. Purple: Taped. Green: Finished. The model geometry stays read-only.
Connection help
If the model cannot connect, check your internet connection and Retry. This site needs Autodesk services; PDF import also needs jsDelivr.
Presentation
Present opens full screen on desktop. This is a sample workspace: schedule and field progress are synthetic, not live project reporting.
